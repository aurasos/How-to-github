Publishing a course on GitHub Pages

How to take interactive lesson files, host them for free, and share one link that opens a clickable course menu.

Choose a part to jump straight to it, or press Start to begin at Part 1. Steps appear one at a time.

Part 1

Publish a new course from scratch

You will move through five steps, in this order.

  1. Prepare your HTML files
  2. Create a new course repository on GitHub
  3. Upload your lesson files
  4. Turn on free web hosting (GitHub Pages)
  5. Create your course menu (README.md)
Part 1, step 1 of 5

Prepare your HTML files

  1. 1

    Have your AI agent generate each lesson as a single, self-contained .html file, with all CSS and JavaScript inline.

  2. 2

    Name your files using only lowercase letters, numbers and dashes. No spaces or special characters.

Part 1, step 2 of 5

Create a new course repository on GitHub

  1. 1

    Log in at github.com.

  2. 2

    Click the + (plus) icon in the top-right corner and select New repository.

  3. 3

    Enter a Repository name, using dashes instead of spaces, for example Course-Name-Here.

    RememberThis name becomes part of your shareable web link.
  4. 4

    Make sure Public is selected.

  5. 5

    Click the green Create repository button.

Part 1, step 3 of 5

Upload your lesson files

  1. 1

    On the new repository set-up screen, look in the middle box under Quick setup and click the blue link uploading an existing file.

  2. 2

    Drag and drop all your .html lesson files into the upload box.

  3. 3

    Wait for every file to finish uploading, then scroll to the bottom and click the green Commit changes button.

Part 1, step 4 of 5

Turn on free web hosting (GitHub Pages)

  1. 1

    Click the Settings tab near the top right of your repository menu.

  2. 2

    In the left sidebar, click Pages, under the Code and automation section.

  3. 3

    Under Build and deployment > Branch, change the dropdown from None to main, then click Save.

  4. 4

    Wait 1–2 minutes and refresh the page. Your live master URL will appear at the top.

Part 1, step 5 of 5

Create your course menu (README.md)

This prevents a 404 error on your main link and gives learners a clickable table of contents.

  1. 1

    Click the <> Code tab at the top left of your repository to go back to your file list.

  2. 2

    Click the green Add a README button. Or click Add file > Create new file and name it README.md.

  3. 3

    Paste your course menu using this Markdown template. The file names in brackets must match your exact file names.

    # Course Title Here

Welcome to the course. Click any lesson below to begin:

### Module 1
* [Lesson 1.1: Lesson Title](module1-lesson1-1-filename.html)
* [Lesson 1.2: Lesson Title](module1-lesson1-2-filename.html)

### Module 2
* [Lesson 2.1: Lesson Title](module2-lesson2-1-filename.html)
  4. 4

    Click the green Commit changes... button in the top right, then confirm.

  5. 5

    Wait 60 seconds, then share your master link.

Part 2

Add or update lessons in an existing course

Use this whenever you finish new lessons, such as Modules 3 and 4, or need to replace an outdated lesson. Everything happens inside your existing repository.

  1. Upload the new or updated HTML files
  2. Add the new lessons to your menu (README.md)
Part 2, A

Upload the new or updated HTML files

  1. 1

    Open your course repository on github.com and make sure you are on the <> Code tab.

  2. 2

    Above the top-right corner of your file list, click Add file > Upload files.

  3. 3

    Drag and drop your new .html files into the box.

    Updating an existing lesson?Upload a file with exactly the same file name as the older version. GitHub overwrites the old file automatically, so your existing links stay intact.
  4. 4

    Click the green Commit changes button at the bottom.

Part 2, B

Add the new lessons to your menu (README.md)

Skip this stepif you only replaced an existing file with exactly the same file name.
  1. 1

    On the <> Code tab, click README.md in your file list. Or scroll down to your menu preview and click the pencil icon in the top-right corner of the box.

  2. 2

    Add your new module heading and lesson links in exactly the same format.

    ### Module 3
* [Lesson 3.1: New Lesson Title](module3-lesson3-1-filename.html)
* [Lesson 3.2: New Lesson Title](module3-lesson3-2-filename.html)
  3. 3

    Click the green Commit changes... button in the top right, then confirm.

  4. 4

    Within 60 seconds, your live course page updates automatically with the new lessons.
